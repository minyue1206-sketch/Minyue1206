
# 🎨 刺绣T恤设计工具

一个简单而强大的工具，可以将你的图片转化为独特的刺绣T恤设计！

## ✨ 功能特点

- **📁 图片上传** - 支持拖拽或点击上传图片
- **✨ 四种刺绣模板** - 经典、密集、稀疏、十字四种效果
- **⚙️ 参数调整** - 可调节绣线密度、T恤颜色、设计大小
- **👕 实时预览** - T恤预览和刺绣效果双视图
- **💾 一键导出** - 保存设计为PNG图片

## 🚀 使用方法

1. 直接在浏览器中打开 `index.html`
2. 上传你的图片
3. 选择刺绣模板和调整参数
4. 预览设计效果
5. 点击"导出图片"保存设计

## 🛠️ 技术栈

- HTML5 + CSS3 (使用 Tailwind CSS)
- JavaScript (原生)
- HTML5 Canvas API

## 📂 文件说明

- `index.html` - 主页面
- `app.js` - 应用逻辑和效果实现
- `.trae/documents/` - 项目文档
